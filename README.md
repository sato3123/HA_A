# ホームパネル（Fire HD 8 用 Home Assistant 操作アプリ）

Proxmox 上の Home Assistant OS（HAOS）を操作する、Fire HD 8 向けの専用アプリです。

## できること

| 機能 | 内容 |
|---|---|
| 時計と天気 | 画面上部に大きな時計・日付・現在の天気・今日の最高/最低気温・数日分の予報 |
| 機器操作 | 種類ごとの専用ボタン（下表）。状態はリアルタイムに反映 |
| 表示する機器の選択 | ⚙ 設定 → 表示する機器 で、名前検索しながらチェック |
| 音声操作 | マイクボタン、または呼びかけ（ウェイクワード）で話しかける |
| AI への質問 | 「〇〇の営業時間を教えて」などを AI が答えて読み上げ。5分以内なら会話の続きも可 |
| 文字入力 | 音声と同じく命令・質問ができ、回答は読み上げ |
| 外出先から利用 | Home Assistant Cloud（Nabu Casa）経由で自動接続。家に戻ると自動でローカルに戻る |
| ログインは1回 | 初回だけ家の中でログイン。パスワードは保存しない |

### 機器ごとの操作

| 種類 | 一覧のタイル | タップで開く詳細パネル |
|---|---|---|
| エアコン | 設定温度 −/＋、運転モード（冷房・暖房・除湿・送風・自動・停止） | 室温・湿度、風量、風向き、プリセット |
| 照明 | オン/オフ、明るさ | 色温度、色（8色） |
| ファン | オン/オフ、風量 | モード、首振り |
| カーテン・シャッター | 開・停止・閉、開き具合 | 同左 |
| スイッチ・シーン・スクリプト | タップで切り替え/実行 | — |

※ ボタンは機器が対応している機能だけ表示されます。

## 1. Home Assistant 側の準備

### 1-1. 基本
1. 「設定 → ユーザー」で、タブレット用の管理者ではないユーザーを作ります。
2. HAOS の VM の IP アドレスをルーターで固定します。
3. 天気：「設定 → デバイスとサービス」に天気の連携（標準の Met.no など）があることを確認します。

### 1-2. AI に答えさせる（営業時間などの質問）
1. 「設定 → デバイスとサービス → 統合を追加」で **OpenAI** を追加し、API キーを入力します。
2. 追加した OpenAI の会話エージェントの設定で、次を選びます。
   - モデル：gpt-4o 以降
   - **Enable web search** をオン（営業時間などのWeb検索に必要）
   - **Include home location** をオン（近くのお店を探しやすくなる）
   - **Control Home Assistant** を Assist に（AI からも機器を操作できるようにする場合）
3. 「設定 → 音声アシスタント」で日本語のアシスタントを開き、会話エージェントに OpenAI を選びます。
4. 同じ画面の **「コマンドをローカルで優先処理する」** をオンにします。照明・エアコンなどの命令は今までどおり速く家の中で処理され、それ以外の質問だけ AI に送られます。

※ Google Gemini 連携の Google 検索機能は「機器を操作しない」設定のときしか使えないため、機器操作と一緒に使うなら OpenAI が向いています。
※ OpenAI の API 利用料がかかります。

### 1-3. 呼びかけ（ウェイクワード）
1. アドオンで **openWakeWord** を入れて起動します。
2. 「設定 → 音声アシスタント」でアシスタントを開き、「ウェイクワード」に openWakeWord と言葉（例：ok_nabu）を選びます。
3. アプリの ⚙ 設定 → 「呼びかけで反応する」をオンにします。

**「OK Google」にしたい場合**
- Fire OS では Google アシスタント自体は動きません。代わりに openWakeWord の **カスタムモデル** を使います。
- 作り方は公式手順のとおりです：https://www.home-assistant.io/voice_control/create_wake_word/ （ブラウザ上で言葉を入力して学習 → できたファイルを `/share/openwakeword` に置く → ウェイクワードの一覧から選ぶ）
- 注意：近くに Google のスマホや Nest スピーカーがあると、それらも同時に反応します。気になる場合は別の言葉をおすすめします。
- Fire の Alexa ハンズフリーがオンだとマイクを取り合うことがあります。「設定 → Alexa → ハンズフリーモード」をオフにしてください。

### 1-4. 外出先から使う（Home Assistant Cloud）
1. 「設定 → Home Assistant Cloud」で Nabu Casa のアカウントにサインインします（有料）。
2. 「リモートコントロール」をオンにし、表示される URL（`https://xxxx.ui.nabu.casa`）を控えます。
3. アプリの ⚙ 設定 →「外出先からの接続」にその URL を入力して保存します。

動きは次のとおりです。
- 家のWi-Fiでサーバーに届くとき：ローカル接続（`http://IP:8123`）
- それ以外：Cloud 経由で接続（画面左上に「外出先（Cloud）」と表示）
- 外出先接続中も1分ごとに確認し、家に戻ったらローカルへ切り替えます。
- 外出先では通信量を抑えるため、呼びかけ待ち受けは止めます（マイクボタンは使えます）。
- アプリが接続するのは「家の中のアドレス」と「登録したリモートURL」だけです。
- 同じ Cloud で Google アシスタント連携もできます（「音声アシスタント → 公開」で Google に出す機器を選び、Google Home アプリで「Home Assistant Cloud by NABU CASA」をリンク）。

## 2. APK の入手

`main` ブランチに変更が入ると、GitHub Actions が自動でビルドします。

1. リポジトリの「Actions」タブで、最新の「Build APK」を開きます。
2. 下部の Artifacts から **HomePanel-apk** をダウンロードし、展開して `app-debug.apk` を取り出します。

PC でビルドする場合は、Android Studio でこのフォルダを開き「Build → Build APK(s)」を実行します。

## 3. Fire HD 8 へのインストール

**ADB（おすすめ）**
1. Fire の「設定 → デバイスオプション → シリアル番号」を7回タップして、開発者オプションを出します。
2. 「開発者オプション → ADBを有効にする」をオンにし、USBでPCとつなぎます。
3. `adb install -r app-debug.apk` を実行します（更新時も同じコマンドで、ログイン情報は残ります）。

**ファイルを直接コピー**
1. APK を Fire にコピーします。
2. 「設定 → セキュリティとプライバシー → 提供元不明のアプリ」で、ファイルアプリを許可します。
3. コピーした APK を開きます。

## 4. 初回起動
1. 家の中で URL（例：`192.168.1.10` → `http://192.168.1.10:8123` に補完）、ユーザー名、パスワードを入力します。
2. マイクの権限を許可します。
3. ⚙ 設定で、外出先用 URL、呼びかけ、使うアシスタント、表示する機器を設定します。

## ファイル構成
- `NetworkGuard.kt`：ローカル/Cloud の自動切り替え、接続先を限定する DNS
- `Auth.kt`：ログイン（login_flow → token）と、暗号化したトークンの保存
- `HaClient.kt`：WebSocket API（状態の購読、サービス呼び出し）
- `VoiceAssistant.kt`：呼びかけ検知 → 音声認識 → 会話（AI） → 読み上げのパイプライン実行
- `MainViewModel.kt`：接続ループ、天気予報、待ち受けループ、設定
- `Ui.kt`：ログイン・ホーム（時計/天気/音声）画面
- `Controls.kt`：機器の種類ごとのタイルと詳細パネル
- `Settings.kt`：設定画面

## 注意
- ログインを何度も失敗すると、HA の設定によってはタブレットの IP がブロックされます（`ip_bans.yaml`）。
- 呼びかけ待ち受け中は、音声を家のサーバーへ送り続けます（1時間あたり約115MB、家の中のみ）。
- アプリのアイコンは未設定です（Android 標準アイコン）。
